# Egg Price Calculator | Animal Agriculture Reform Collaborative

A suite of agricultural calculators to help farmers make informed pricing and management decisions.

## Calculators

- **Egg Price Calculator** – Calculate sustainable pricing for pasture-raised eggs
- **Meat Price Calculator** – Determine cost-effective pricing for meat products
- **Stock Density Calculator** – Plan optimal stocking rates for grazing operations

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Development

```sh
# Install dependencies
npm install

# Start dev server
npm run dev
```
